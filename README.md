# CLEC Episode Organizer

把一集 CLEC 內容整理成「同一頁就能看懂、查證與深讀」的繁體中文 Obsidian 知識頁。

這個 skill 以 CLEC 00574〈消費才是經濟之母，有錢人消費是道德！〉的實際整理流程為基礎，保留來源、摘要、逐字稿與人工核對之間的關係。它不會因為同一集出現在不同平台，就建立多篇重複文章。

## 它能做什麼

- 依 CLEC 五位數編號合併同一集內容。
- 收集並標示 X、pCloud、Google Drive、Bilibili、Odysee、RSS／Podcast 等來源。
- 把已確認、待確認與未找到的來源分開。
- 建立「30 秒看懂、3～5 分鐘理解、深入閱讀」三層內容。
- 保留原始繁體逐字稿，另外建立較好讀的整理版。
- 將學員匿名為「學員 1、學員 2……」。
- 把整理版逐字稿嵌入單集主頁，閱讀時仍在同一頁。
- 預設不發布到網站，先保留人工審核。

## 適合什麼情況

當你要處理單一 CLEC 編號，並希望：

- 整理或重寫單集知識頁。
- 合併散落在不同平台的存檔。
- 補齊來源與來源狀態。
- 把 AI 逐字稿整理成自然、可閱讀的繁體中文。
- 區分 James 老師主講與後段學員問答。
- 沿用 00574 的格式處理後續集數。

## 安裝方式

將整個 `clec-episode-organizer` 資料夾放入 Codex 的 skills 目錄，並保留以下結構：

```text
clec-episode-organizer/
├── SKILL.md
├── agents/
│   └── openai.yaml
├── assets/
│   └── episode-page-template.md
├── references/
│   ├── 00574-transcript-config.json
│   └── 00574-verified-example.md
└── scripts/
    └── build_readable_transcript.mjs
```

安裝後，可直接指定：

`Use $clec-episode-organizer to organize CLEC 00574.`

也可以用自然中文要求，例如：「請用 CLEC 節目整理 skill，整理 00575 並合併所有已確認來源。」

## 整理後的頁面結構

### 1. 30 秒看懂

包含一句話重點、3～5 個主要重點，以及觀看與閱讀入口。

### 2. 3～5 分鐘理解

先說明這集在回答什麼問題，再依內容整理背景、主要論證、策略或值得思考的問題。

### 3. 深入閱讀

包含術語解釋、來源狀態、證據限制、完整整理版逐字稿，以及原始逐字稿連結。

## 逐字稿原則

- 原始逐字稿不覆寫。
- 整理版只調整段落、標題、標點、已確認名詞與相鄰重複。
- 不加入固定的 00:05、00:10 等時間分段。
- 先保留 James 老師依講義主講的順序，再整理主持人與學員問答。
- 學員按第一次上台順序匿名編號。
- 主持人姓名必須有來源或經使用者確認。
- 聽不清楚的詞標示為「〔需核對〕」，不自行猜測。

- Google Drive 影片典藏資料夾。
- pCloud 簡報。
- Bilibili 影片備份。
- Odysee 與 RSS／Podcast 的待確認狀態。
- 主持人為 Kate。
- `Cloudhouse` 修正為 `Clubhouse`。
- 「納子一百／那指一百」修正為「納斯達克 100（QQQ）」。

這些修正只代表 00574 已確認的結果，不應無條件套用到其他集數。

## 發布與資料安全

- 預設 `publish_to_website: false`。
- 找到但無法確認的來源，標示為待確認。
- 不建立猜測性的 Odysee、RSS 或其他平台連結。
- 不把投資內容改寫成獲利保證或個人投資建議。
- 不在 skill 中寫死使用者家目錄、密碼、Token 或 API Key。
